# Switch AI Discord Bot (Node.js & JavaScript)

Fastest way to test your Discord bot with Switch AI integration in under 60 seconds.

## Quick Start
```bash
# 1. Install dependencies
npm install

# 2. Add your token
cp .env.example .env
# Edit .env and paste your DISCORD_BOT_TOKEN

# 3. Start the bot
npm start
```

## How to Test in Discord
1. Invite your bot to your Discord server (with `Message Content Intent` enabled in the Discord Developer Portal).
2. In any channel, type:
   `!triage Cache invalidation bug on user profile page`
3. Click the interactive **[Approve & Execute]** button to test the human-in-the-loop approval requirement for the hackathon!
